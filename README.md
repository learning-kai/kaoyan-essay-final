# 考研英语一作文 & 考研多科背诵网站

基于学习科学（主动回忆、FSRS-5 间隔重复、Worked Examples、渐进撤除提示、错误驱动重排、交错练习与生成效应）设计的考研备考工具，现已完整集成 **考研英语一小作文**、**考研英语一大作文（图画 + 可选图表）**、**考研数学公式默写**、**27 考研政治一页纸** 与 **GitHub 私有 Gist 双向云同步**。

## 本地运行与测试

```bash
npm install
npm run dev      # 启动本地开发服务器
npm test         # 运行全部单元测试（逐字比对 / 数据迁移 / 判分对齐 / 调度 / 云同步 / 素材包字数 / 图表校验）
npm run build    # 生成支持 PWA 离线缓存的静态站点（dist/）
```

## 内容疑点（未修改源码，仅按要求记录）

### 小作文部分
1. **介绍类第 3 句连接词**：`intro.body3` 原文以 `Taken together,` 开头，而非通用骨架中的 `Last but not least,`（代码已严格按原文保留）。
2. **祝贺信结尾句**：`congrats.closing` 使用独立结尾 `I sincerely hope that you will make full use of this opportunity to [期待成效].`，原文备注“也可以换成通用结尾”；当前按原文保留独立结尾句。
3. **邀请信主体句数**：邀请信主体为 4 句（含 `More specifically,`），其余 6 类均为 3 句，已按原文及单测要求保留。
4. **通知落款撇号**：原文为 `The Students' Union`，已在规范化层统一中英文撇号。

### 大作文部分
1. **`P1.S3`（意义句）固定词较长**：该句固定部分共 31 词（`When its positive potential is properly realized, ... thereby enhancing the accuracy of their judgment.`），是 11 句中最长的记忆难点；代码已逐字保留，学习页采用 40% → 80% 两阶段渐进完形帮助分块攻克。
2. **`P2.S3` 默认媒介 `social media` 的适用范围**：默认填词假定话题经由社交媒体引发关注；若真题画面更偏重线下传统或制度场景，建议在规划卡「展开更多可选槽位」中将 `MEDIA` 替换为 `public opinion` 或 `the media`。
3. **保留可选句 `P2.S4` 时的篇幅**：附录 A 10 句必写骨架本身固定词约 155 词，代入常见素材包后约 195–218 词；若再叠加 15+ 词的 `P2.S4` 往往会超过 220 词上限，因此样例页与规划卡默认省去 `P2.S4`（仍提供一键开关供自行比较）。
