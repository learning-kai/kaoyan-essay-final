# 考研英语一小作文背诵网站（全四阶段完整版）

基于学习科学（主动回忆、FSRS-5 间隔重复、渐进撤除提示、错误驱动重排、交错练习与生成效应）设计的考研英语一小作文背诵工具。所有中英文模板均逐字转录自《小作文_最终背诵版.md》。

## 本地运行与测试

```bash
npm install
npm run dev      # 启动本地开发服务器
npm test         # 运行全部 29 项单元测试（原文逐字比对 / 判分 / 调度 / 错题 / 批改 / 统计与备份）
npm run build    # 生成支持 PWA 离线缓存的静态站点（dist/）
```

## 全四阶段已完成功能

1. **第一阶段 MVP**：7 套模板逐字转录与校验、共用句去重、LCS/Levenshtein/词形判分、FSRS-5 调度、模板库、4 步学习、专注复习、IndexedDB 持久化。
2. **第二阶段**：今日首页（倒计时、任务卡片、9 课可展开进度、本周热力图）、纸笔模式（`Space` 翻面 + `1–4` 自评）、错题本（高频错词统计 + 只练错题）、深色暖黑主题与设置页、全局快捷键与 `?` 帮助面板。
3. **第三阶段**：实战模式（21 道原创考研模拟题含 6 道易混淆题、20 秒识题、15 分钟信纸写作、逐句批改）、P/F/O/E/T 五类专项卡片、考前 3 天冲刺模式。
4. **第四阶段（本次完成）**：
   - **学习统计页（`/stats`）**：Recharts 驱动、严格沿用设计令牌配色——各模板掌握度横向分段条、未来 14 天复习量预测柱状图、整篇实战用时折线图（含 10 分钟目标线）与题型识别正确率。
   - **PWA 离线支持**：集成 `vite-plugin-pwa`，支持离线访问与添加到手机桌面。
   - **JSON 备份与恢复**：在设置页支持一键导出全部学习进度与偏好设置，并在新浏览器一键导入恢复。
   - **移动端打磨**：底部 5 项标签栏（今日 / 学习 / 复习 / 实战 / 更多抽屉）与安全区适配。

## 内容疑点（未修改源码，仅按要求记录）

1. **介绍类第 3 句连接词**：`intro.body3` 原文以 `Taken together,` 开头，而非通用骨架中的 `Last but not least,`（代码已严格按原文保留）。
2. **祝贺信结尾句**：`congrats.closing` 使用独立结尾 `I sincerely hope that you will make full use of this opportunity to [期待成效].`，原文备注“也可以换成通用结尾”；当前按原文保留独立结尾句。
3. **邀请信主体句数**：邀请信主体为 4 句（含 `More specifically,`），其余 6 类均为 3 句，已按原文及单测要求保留。
4. **通知落款撇号**：原文为 `The Students' Union`，已在规范化层统一中英文撇号。
